## How to Use

1. **Compile:** Use GCC compiler to compile any C file
   ```bash
   gcc filename.c -o filename.exe
   ```

2. **Run:** Execute the compiled program
   ```bash
   ./filename.exe
   ```

3. **Follow prompts:** Enter the required input values as prompted by each program
